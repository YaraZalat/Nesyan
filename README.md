# NESYAN 🧠

### AI & IoT-Based Alzheimer's Care System

**NESYAN** is a Flutter-based mobile healthcare application designed to support Alzheimer's patients, caregivers, and relatives through medication reminders, appointments, daily routines, patient monitoring, and assistance features.

The system combines **mobile development, AI, and IoT technologies** to provide a supportive and safer environment for Alzheimer's patients and their caregivers.

---

## 🎯 Project Overview

Alzheimer's patients may require continuous support with daily activities, medication schedules, appointments, and personal safety.

NESYAN aims to simplify patient care by providing caregivers and relatives with tools for:

* Medication and appointment management
* Daily routine organization
* Patient location monitoring
* Safe zone management
* Emergency assistance
* Cognitive and entertainment activities
* AI-powered assistance

---

## ✨ Key Features

### 💊 Medication Reminders

Helps patients and caregivers manage medication schedules and receive reminders.

### 📅 Appointment Management

Allows important appointments to be organized and managed.

### 📝 Daily Routines

Supports patients with organizing and following their daily routines.

### 📍 Map & Location Monitoring

Provides map-based functionality for monitoring the patient's location.

### 🛡️ Safe Zone

Allows caregivers to define designated safe areas and monitor the patient's location relative to these areas.

### 🚨 SOS / Emergency Assistance

Provides an emergency assistance feature for situations where immediate support may be required.

### 👨‍👩‍👧 Caregiver & Relative Support

Provides features designed to help caregivers and relatives monitor and support the patient.

### 🧠 Mind Games

Includes cognitive and entertainment games designed for patient engagement.

### 🤖 AI-Powered Features

Integrates AI-powered functionality to support patient assistance and monitoring.

### 📊 Cognitive Assessment

Provides functionality related to cognitive assessment and monitoring.

## 🏗️ Architecture

NESYAN follows a **Clean Architecture** approach to improve separation of concerns, maintainability, and scalability.

The application is organized around:

```text
Presentation
     ↓
Domain
     ↓
Data
     ↓
External Services / APIs
```
